功能：加载预处理 pkl → 构建 KAN 模型 → 训练 → 保存 best/final

接收命令行参数：--config （YAML 配置文件的路径）

执行流程：

1. 解析 --config，加载配置，获取 variant
2. 从 pipeline/output/{variant}/data/preprocessed_{variant}.pkl 加载数据
3. 构建模型：
   input_dim = len(cfg['data']['features'])
   hidden = cfg['model']['hidden_layers']
   width = [input_dim] + hidden + [1]
   model = KAN(width=width, grid=cfg['model']['grid'], k=cfg['model']['k'], seed=cfg['model']['seed'], save_act=False)
4. 调用 common.get_optimizer(model, cfg) 获取优化器
5. 调用 common.get_scheduler(optimizer, cfg) 获取调度器
6. 调用 common.get_criterion(cfg) 获取损失函数
7. 转为 PyTorch tensor，送到 device
8. 训练循环（epochs = cfg['train']['epochs']）：
   - 按 batch_size 分批前向传播
   - 计算损失
   - 反向传播 + 梯度裁剪（如果 cfg['train']['gradient_clip'] > 0）
   - 更新参数
   - 调度器 step（每个 epoch 或每个 batch，取决于调度器类型）
   - 记录 train_loss
   - 早停判断：监控 train_loss，patience 和 min_delta 从 cfg 读取
9. 保存 checkpoint 到 output_path(variant, 'models', 'kan_best_{variant}.pth')：
   必须包含：
   - 'model_state': model.state_dict()
   - 'config': cfg  （完整配置字典）
   - 'config_yaml': yaml.dump(cfg)  （字符串形式的完整配置）
   - 'epoch': 当前轮数
   - 'train_loss': 最佳损失值
   - 'variant': variant
10. 同样保存 final 到 'kan_final_{variant}.pth'
11. 打印训练摘要（中文）：变体名、最终 loss、保存路径
